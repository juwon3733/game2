# 17. 6장 전체 완성 계획 (2026-10-26~)

목표: 1장~종장을 **그림까지 다 넣은 상태**로 한 번에 완성한다. 15번 계획(그림 없이 할 수 있는 것)은 끝났다.
지금 그림은 284장 중 79장만 있다(배경 7, 컷 35). 3~6장은 거의 임시 그림이라 퍼즐이 컷 설명 글로 풀린다.

## 1. 그림 받기 (사용자 → GPT 에이전트)
- `docs/GPT_REQUEST.md`의 글을 그대로 보낸다. 1차(교체) → 2차(없는 상반신) → 3차(UI) → 4~8차(장별) → 9차(CG).
- 프롬프트가 바뀌면 `node tools/export-prompts.mjs` 후 요청 목록도 같이 고친다.

## 2. 그림 검수 (Claude, 묶음이 올라올 때마다)
- 이미지를 직접 열어 본다: 스타일(회색 8단계 + 포인트 1색, 디더), 같은 인물인지, `must_show` 단서가 크게 보이는지, 상반신 배경 투명.
- 그림체가 다르면 `tools/dither-cut.py`로 맞춘다. 고칠 수 없으면 PR에 이유를 달고 다시 요청 목록에 넣는다.
- 짚을 곳(`spots`) 좌표를 그림에 맞춘다. `node tools/spot-overlay.mjs <폴더> [컷 id…]`가 그림 위에 상자를 그려 준다(초록=단어, 빨강=헛짚기).
- **장 하나의 그림이 다 들어오면 그 장을 "그림만 보고" 다시 플레이한다.** 설명 글이 사라진 상태에서
  - 정답이 그림으로 하나로 정해지는지, 다른 컷도 답처럼 보이지 않는지
  - 시계가 보이는 컷이 기준점 2~4장뿐인지(시각 정렬로 풀리지 않게)
  - 반대로 그림에 단서가 안 보여 못 푸는 곳이 없는지
  를 확인하고, 문제면 프롬프트를 고쳐 다시 받거나 질문·정답을 고친다.

## 3. 그림 없이 남은 이야기·추리 (Claude, 그림 기다리는 동안)
- 4장 교차 심문 마지막 "누가 착각/거짓말" 선택: 고를 게 없다. 근거를 하나 더 요구하게.
- 종장: 쿠로가네가 상자를 몰래 빼 둔 사실이 너무 늦게 나온다(4·5장에 복선). 아사기리 사연이 얇다(5장에 한 장면).
- 시즌 전체 날짜·시각 대조표(`docs/18_timeline.md`): 장마다 따로 고치며 어긋난 숫자가 없는지.

## 4. 플레이 기록 (Claude)
- 장면마다 걸린 시간, 오답·힌트 수를 저장하고, 설정에서 파일로 내보낸다(다른 사람 플레이를 받기 위해).
- `12_story_plan.md` §2-1 목표 시간과 비교해 너무 길거나 짧은 장을 조정한다.

## 5. 마무리 (그림이 다 들어온 뒤)
- 처음부터 종장까지 전부 다시 플레이(엔딩 3개). 자동 검사(`smoke`, `playthrough`, `lint-text`)와 함께.
- 실제 사람 2~3명 플레이테스트 → 4번 기록으로 막힌 곳 고치기.
- 타이틀 키아트 원본 화질, 크레딧, 갤러리 점검.

## 확인 방법
- 단계마다 `node tools/lint-text.mjs`, `node tools/check-assets.mjs`, `node tools/export-prompts.mjs --check`, `tools/smoke.mjs`, `tools/playthrough.mjs`.
