# 15. 그림 없이 할 수 있는 품질 올리기 (2026-10-26~)

그림은 GPT 파이프라인을 기다리고, 그동안 코드·글·소리·연출로 올릴 수 있는 것을 한다.
판단 기준: **처음 10분이 재밌는가 / 추리가 "내가 풀었다"는 느낌인가 / 끝까지 막힘 없이 가는가.**

## 지금 약한 곳 (플레이해 보고 느낀 것)

| 영역 | 문제 |
|---|---|
| 첫인상 | 1장 시작이 사무실 브리핑. 사건의 충격(추락)이 직접 안 보이고 설명으로만 들어온다 |
| 추리 | 그림이 없는 컷은 설명 글이 그대로 보여 답이 너무 쉽다. 질문마다 정답이 여러 개로 보이는지 전수 점검은 아직 안 했다 |
| 힌트 | 토와 힌트는 "1번: 고정 문장, 2번: 칸 하나 고정"뿐. 지금 어디서 막혔는지와 무관 |
| 수첩 | 컷·물증·단어·대사·인물만 있다. 사건 개요, 지금까지 밝혀진 것, 다음 할 일이 없어 쉬었다 오면 길을 잃는다 |
| 인물 | 사건 밖에서 레이·코하루·토와·쿠로가네가 이야기하는 장면이 적다. 관계가 장마다 리셋되는 느낌 |
| 연출 | 결정적 순간이 대사창 한 줄로 지나간다. 만화 컷을 쓰는 게임인데 "만화 페이지"로 보여 주는 장면이 없다 |
| 소리 | 심문이 한 곡으로 길게 간다. 증인 마음이 줄어들 때, 마지막 반박 직전 같은 긴장 변화가 소리로 안 온다 |
| 글 품질 | 전수 점검은 했지만 다시 쓰면 또 생긴다. 자동으로 걸러 주는 장치가 없다 |
| 모바일 | 손가락으로 누르기 작은 버튼, 세로 화면 안내만 있음, 첫 로딩이 느림(그림·소리 한꺼번에) |

## 할 일 (순서대로)

### 1단계 — 글이 다시 나빠지지 않게 (반나절)
- **대사 린트** `tools/lint-text.mjs`: 모든 대사를 뽑아 규칙 검사, CI에 넣는다.
  - `X인 게 아니라 Y` 패턴, "…"로 시작하는 줄 비율, 조사 자리표시 누락, 같은 문장 반복, 3박자 나열, "당신"(존댓말 상대), 장 안 날짜 표기, 인물별 말투(반말/존댓말) 표.
- **말투 표** `docs/16_voice.md`: 인물별 호칭·말끝·자주 쓰는 말·쓰면 안 되는 말.

### 2단계 — 추리가 "내가 풀었다"가 되게 (1~2일)
- **그림 없는 컷 처리**: 임시 컷은 설명 글 대신 핵심을 가린 "스케치"로(실루엣·소품 이름만). 답이 글로 새지 않게.
- **질문 전수 점검**: 모든 반박·결론 질문에 대해 "다른 컷도 답 같아 보이나"를 표로. 맞으면 둘 다 정답 처리하거나 질문을 좁힌다.
- **상황 힌트**: 토와 힌트를 지금 상태에 맞게(어느 증언에서 오래 머무는지, 어느 칸 사이가 틀렸는지, 안 읽은 잔상이 어느 구역에 남았는지).
- **추리 메모**: 증언마다 "수상함" 표시를 달아 두면 수첩에 모인다(플레이어가 직접 정리하는 맛).

### 3단계 — 이야기와 인물 (2~3일)
- **콜드 오픈**: 1장 첫 장면을 "추락 직전 3초"로 시작(소리 + 흔들리는 화면 + 컷 한 장) → 그다음 브리핑.
- **수첩 「사건」 탭**: 장마다 사건 개요, 밝혀진 것(체크), 아직 모르는 것(?), 다음 할 일. 이어하기로 돌아오면 「지난 이야기」 3줄.
- **막간 대화**: 장 사이마다 사무실에서 2~3분짜리 장면(코하루가 레이 커피 취향을 알아 가는 것, 토와의 모니터 너머 사생활, 쿠로가네의 시계). 선택지 하나씩, 여백 엔딩 조건과 연결.
- **[말 걸기] 대사 늘리기**: 조사 장소에 있는 인물마다 사건 외 대사 1~2개.

### 4단계 — 연출 (2일)
- **만화 페이지 컷신**: 결정적 순간(1장 끌어당김, 2장 앙코르, 3장 10분, 4장 불 속, 5장 계단 아래, 종장 넘겨주는 손)을 이미 있는 컷들로 만화 한 페이지처럼 칸이 하나씩 열리게. 그림이 들어오면 그대로 좋아진다.
- **심문 긴장 단계**: 증인 마음이 줄 때 곡 필터·템포 변화, 마지막 반박 직전 정적 + 심장 소리, 증언 붕괴를 증인마다 다르게(찢김/번짐/지워짐).
- **장 끝 "다음 장 예고"**: 1~2컷 + 한 줄.

### 5단계 — 다듬기 (1일)
- **모바일**: 버튼 크기, 첫 로딩 화면(필요한 것만 먼저 받기), 세로 화면 안내 개선.
- **설정**: 글자 크기, 흔들림 끄기 따로, 자동 진행 속도.
- **업적·기록**: 장마다 S 랭크, 노힌트, 여백 컷 수집을 타이틀에서 확인.

## 확인 방법
- 단계마다 `tools/playthrough.mjs`(전 장 자동 풀이) + `tools/smoke.mjs` + 새 `lint-text` 통과.
- 1·3단계 뒤에는 처음부터 직접 플레이 로그를 다시 뽑아 읽는다.
