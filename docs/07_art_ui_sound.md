# 07. 아트 · UI · 사운드

## 1. 아트 방향 한 줄 요약

> **"애니 캐릭터가 사는 늦여름 도시를, 만화 원고지 위에 도트로 그린다."**

- 캐릭터: 애니풍. 큰 눈, 명확한 실루엣, 캐릭터마다 테마 색.
- 배경: 차분한 채도의 늦여름. 노을, 소나기 뒤 젖은 아스팔트, 형광등.
- UI와 컷: 흑백 원고지 + 스크린톤 + 포인트 컬러. 현실 화면(컬러)과 잔상(흑백 + 한 가지 색)을 시각적으로 구분한다.

## 2. 해상도와 규격

| 항목 | 규격 | 비고 |
|---|---|---|
| 기본 해상도 | **480 × 270** | 16:9. 1920×1080에서 정수배 4배 |
| 필드 타일 | 16 × 16 | |
| 필드 캐릭터 | 24 × 40 (2.5등신 미만 X, 약 3등신) | 4방향 × 걷기 4프레임 |
| 대화 초상 | 96 × 96 | 상반신. 표정 4~6종, 눈 깜빡임 2프레임, 입 2프레임 |
| 컷 (보관함/배열용) | **128 × 96** | 4:3. 원고지 칸에 그대로 들어감 |
| 컷 (확대/돋보기용) | 같은 이미지를 정수배 확대 | 가짜 컷 이음매는 이 해상도 기준 1px 단위로 설계 |
| 일러스트 배경 (카페, 병원 등 연출 씬) | 480 × 270 | 장당 2~3장 |
| 텍스트 | 갈무리11 / 갈무리9 (OFL, 도트 한글 폰트) | 손글씨 말풍선(시오리)은 별도 도트 손글씨 제작 |

## 3. 팔레트

- **현실 화면**: 기본 32색 팔레트 + 장별 강조색 4색.
  | 장 | 강조색 테마 |
  |---|---|
  | 1장 | 늦여름 저녁 주황, 맨션 복도 형광 초록 |
  | 2장 | 네온 분홍, 무대 조명 5색 |
  | 3장 | 메이드 카페 파스텔 |
  | 4장 | 항만 야간 청록, 경고등 빨강 |
  | 5장 | 노을 → 불길 → 새벽 남색 |
- **잔상(컷)**: 흑 / 백 / 회색 2단계 + **시점 주인의 테마 색 1색**.
  - 예: 미츠루 시점 컷은 하늘색 포인트, 타이가 시점은 금색 포인트, 히마리는 분홍.
  - 플레이어가 색만 보고도 "누구 시점인지" 감을 잡게 한다.
- **스크린톤**: 4×4 Bayer 디더 패턴 3단계 + 망점(도트) 패턴 2단계 + 가로 줄무늬 1종. 편집 이음매 퍼즐은 이 패턴들의 어긋남으로 설계.

## 4. 컷 제작 방식: 모듈 조립

1인 개발에서 가장 큰 리스크는 **컷 수**(전체 약 150장)다. 모든 컷을 처음부터 그리지 않는다.

```
컷 = 배경 레이어 + 인물 포즈 레이어 + 소품 레이어 + 효과 레이어(효과선/의성어) + 말풍선
```

| 레이어 | 재사용 방식 |
|---|---|
| 배경 | 장소당 2~4 앵글만 그리고 여러 컷에서 공유 |
| 인물 포즈 | 캐릭터당 컷용 포즈 8~12종을 그려 두고 조합 |
| 소품 | 머리핀, 상자, 휴대폰 등 단서 소품은 상태별 스프라이트 |
| 효과 | 효과선, 집중선, 의성어는 공용 라이브러리 |
| 왜곡 | 낙서, 크레용, 흐림 등은 셰이더/오버레이로 처리 (컷마다 다시 그리지 않음) |

- 컷 에디터(개발 도구)에서 레이어를 조합하고 상태 태그를 같이 저장한다. → 04_systems.md의 데이터 구조와 연결.
- 진상이 드러나는 핵심 컷(장당 2~3장)만 전용 일러스트로 공들여 그린다.

## 5. 화면 구성 (UI)

### 탐색 화면
```
┌──────────────────────────────────────────┐
│ [장 제목]                     [수첩] [메뉴] │
│                                          │
│            탑뷰 맵 (480×270)              │
│                                          │
│                                          │
├──────────────────────────────────────────┤
│ [초상] 대사 박스 (원고지 질감, 하단 3줄)      │
└──────────────────────────────────────────┘
```

### 컷 배열 화면
```
┌───────────────────────┬──────────────────┐
│  원고지 (B4 비율)        │  컷 묶음            │
│  ┌──────┬──────┐       │  ┌───┐ ┌───┐      │
│  │  1   │  2   │       │  │ A │ │ B │      │
│  ├──────┼──────┤       │  └───┘ └───┘      │
│  │  3   │  4   │       │  ┌───┐ ┌───┐      │
│  └──────┴──────┘       │  │ C │ │ D │      │
│                        │  └───┘ └───┘      │
│                        │ [대사 조각]          │
├───────────────────────┴──────────────────┤
│ [토와 힌트]       [돋보기]       [페이지 넘기기] │
└──────────────────────────────────────────┘
```
- 배경은 작업 책상. 지우개 가루, 펜, 커피 얼룩(레이의 책상).
- 컷을 집으면 살짝 기울고 그림자가 생긴다. 칸에 놓으면 "착" 하고 붙는 소리와 1프레임 흔들림.

### 심문 화면
- 상단: 증인 초상(크게), 잉크병 게이지 3칸.
- 중앙: 증언 페이지(가로로 넘기는 컷 띠). 현재 컷이 확대.
- 하단: 내 컷 보관함(가로 스크롤), [파고들기] 버튼, 코하루 개입 버튼(사용 가능할 때만 빛남).

### 연출 키 비주얼
| 연출 | 설명 |
|---|---|
| 잔상 읽기 | 화면이 스크린톤으로 덮이고 원고지가 날아와 컷이 그려짐 |
| 반박 성공 | 컷이 꽂히며 집중선, 큰 의성어 "탁!", 화면 흔들림 |
| 왜곡 벗겨짐 | 낙서는 찢어지고, 크레용은 번지고, 생략은 잉크가 스며들 듯 채워짐 |
| 페이지 재생 | 칸이 하나씩 밝아지며 말풍선이 타이핑되고 효과음 재생 |
| 장 클라이맥스 | 페이지가 펼침면(양면)으로 확장되는 대형 컷 |

## 6. 사운드

### 음악 방향
- **로파이 시티팝 + 피아노**. 늦여름 저녁의 나른함.
- 장별 메인 테마는 1장의 피아노 모티프(미츠루가 치던 곡)를 변주한다. 5장에서 이 곡이 시오리와 레이가 듣던 곡이었다는 연결(가능하면).
| 트랙 | 용도 |
|---|---|
| 잔상과의 오후 | 사무실, 일상 |
| 현장 | 조사 (장별 편곡) |
| 원고 책상 | 컷 배열 퍼즐. 리듬감 낮고 집중되는 곡 |
| 대질 | 심문. 템포 업 |
| 순서가 틀렸어 | 반박 성공 후 몰아치는 곡 |
| 여백 | 카페, 에필로그. 어쿠스틱 |
| 같은 하루 | 5장 최종 재구성 |

### 효과음
- **의성어 = 효과음.** 컷 속 "쿵", "쏴아", "탁"은 페이지 재생 시 실제 효과음으로 난다. 퍼즐 단서로 의성어를 쓰는 경우 소리로도 구분 가능해야 한다.
- 펜 소리, 원고지 넘기는 소리, 스크린톤 칼질 소리를 UI 효과음으로.
- 대사는 음성 없이 캐릭터별 **블립음**(음높이/음색 다르게). 시오리만 블립 없이 무음 + 종이 사각거리는 소리.

## 7. 레퍼런스 무드

| 요소 | 레퍼런스 방향 |
|---|---|
| 도시와 계절 | 늦여름 일본 지방 도시 애니(노을, 계단 골목, 매미) |
| 도트 밀도 | 세밀한 현대 도트 배경 작품들(네온과 실내 조명 표현) |
| 원고지 UI | 실제 만화 원고지: 재단선, 안쪽 테두리선, 파란 연필 밑그림 |
| 컷 그림체 | 흑백 만화 + 스크린톤 + 한 가지 포인트 색 |
