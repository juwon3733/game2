# 03. 캐릭터

> 원칙: **애니 속성으로 첫인상을 잡고, 그 속성 뒤의 사람을 보여준다.**
> 모든 주요 캐릭터는 "겉 속성 / 속마음 / 숨긴 것" 세 겹으로 설계한다.

## 잔상과

### 🌙 시노노메 레이 (東雲 レイ) — 주인공
| 항목 | 내용 |
|---|---|
| 나이 | 22 |
| 소속 | 잔상과 조사관 (독자) |
| 겉 속성 | 다운계 무기력, 귀차니스트 |
| 외형 | 반쯤 감긴 눈, 다크서클, 헝클어진 흑발 숏컷, 오버사이즈 회색 후드 위에 낡은 트렌치코트, 항상 캔커피. 오른손 검지에 펜 굳은살. |
| 테마 색 | 새벽빛 남색 + 연보라 |
| 말버릇 | "…순서가 틀렸어." / "귀찮아. 근데 틀린 건 더 귀찮아." |

**성격**
- 사람에게 관심 없는 척하지만 컷 속 사람의 감정은 누구보다 정확히 읽는다.
- 말수가 적고 결론부터 말해서 오해를 산다. 코하루가 통역 역할을 한다.
- 단 것을 싫어하는데 캔커피는 꼭 가당. 본인은 모순을 인정하지 않는다.

**숨긴 것**
- 6년 전 8월 31일 하루의 기억이 통째로 없다. 본인은 "그날 감기로 누워 있었다"고 알고 있다.
- 만화를 그렸던 과거가 있지만 지금은 펜을 잡지 않는다. 굳은살만 남았다.

**아크**
기억을 지운 쪽을 택했던 사람이 기억을 마주하는 이야기. "읽기만 하던" 사람이 마지막에 **직접 한 컷을 그리는** 사람이 된다.

**게임에서의 역할**: 플레이어 시점. 컷을 수집하고 배열하는 주체. 대사 선택지는 레이의 말투 안에서만 고른다(무뚝뚝 / 핵심 찌르기 / 침묵).

### ☀️ 히나타 코하루 (日向 小春) — 파트너
| 항목 | 내용 |
|---|---|
| 나이 | 20 |
| 소속 | 잔상과 배치 신입 형사 (독자 아님) |
| 겉 속성 | 겐키, 열혈, 강아지계 |
| 외형 | 주황빛 갈색 사이드 포니테일, 큰 눈, 하늘색 머리끈. 정장 재킷에 운동화. 형사 수첩에 스티커가 덕지덕지. |
| 테마 색 | 햇살 주황 + 하늘색 |
| 말버릇 | "선배! 선배선배!" / "괜찮아요, 천천히 말해주세요." |

**성격**
- 능력은 없지만 사람의 표정과 말투를 읽는 감각이 뛰어나다. 심문의 공감 담당.
- 실수가 많고 넘어지는 일도 많다. 그런데 결정적인 순간에 절대 물러서지 않는다.
- 레이의 무뚝뚝한 결론을 사람들이 받아들일 수 있게 풀어서 전한다.

**숨긴 것**
- 6년 전 화재로 죽은 순경 **히나타 소타**의 여동생. 오빠의 죽음이 정말 사고였는지 확인하려고 잔상과에 지원했다.
- 레이가 그날 현장에 있었다는 사실은 모른다. (4장에서 알게 됨)

**아크**
진실을 알기 위해 왔지만, 진실이 누군가에게 상처가 된다는 걸 알고 흔들린다. 결국 "알아야 놓아줄 수 있다"는 결론에 도달하고, 레이의 등을 민다.

**게임에서의 역할**: 심문 파트 힌트 담당. 증인의 감정 게이지가 위험해지면 끼어들어 분위기를 바꿀 수 있다(장당 사용 횟수 제한).

### 🍭 쿠로가네 겐지 (黒鉄 源二) — 반장
| 항목 | 내용 |
|---|---|
| 나이 | 47 |
| 소속 | 잔상과 반장, 경부 |
| 겉 속성 | 피곤한 아저씨, 츤데레 상사 |
| 외형 | 꾸깃한 셔츠, 느슨한 넥타이, 반백의 수염, 금연 중이라 항상 막대사탕(딸기맛). 오래된 손목시계. |
| 테마 색 | 철회색 + 딸기 분홍 |
| 말버릇 | "알아서 해. 책임은 내가 진다." / "…사탕 하나 줄까." |

**성격**
- 의욕 없어 보이지만 윗선과 언론의 압력을 혼자 막고 있다.
- 잔상과를 만든 사람. 레이를 데려온 사람.

**숨긴 것**
- 6년 전 화재 사건의 담당 형사였다. 현장에서 연기에 질식해 쓰러진 16살 레이를 발견했다.
- 사건이 위에서 "사고로 종결"하라는 압력을 받았을 때, 저항하는 대신 **레이의 존재를 기록에서 빼는 것**으로 레이를 언론과 하쿠요로부터 지켰다. 그 대가로 진실을 묻었다.
- 레이가 기억을 지운 것도 알고 있었다. 그래서 레이를 곁에 두었다.

**아크**
지켜주려고 진실을 덮은 어른. 4장에서 코하루에게 사실을 털어놓고, 5장에서 경찰 기록을 걸고 증언한다.

### 💻 토와 (トワ) — 분석관
| 항목 | 내용 |
|---|---|
| 나이 | 불명 (본인은 "영원히 17살"이라고 주장) |
| 소속 | 잔상과 외부 협력 분석관 |
| 겉 속성 | 히키코모리 천재 해커, 독설 |
| 외형 | 화면에는 **아바타 도트**로만 등장. 고양이귀 헤드폰, 담요를 망토처럼 두른 2등신 캐릭터. 본체는 끝까지 안 나온다(에필로그에서 손만 나옴). |
| 테마 색 | 모니터 초록 + 담요 크림색 |
| 말버릇 | "에러. 네 추리에 에러가 있어." / "…칭찬해도 아무것도 안 나와." |

**성격**
- 사무실 모니터와 레이의 스마트폰으로만 대화한다.
- 수집된 컷을 디지털로 분석해서 그림자 각도, 색온도, 픽셀 패턴을 수치로 비교해준다.
- 쓴소리를 하지만 팀이 위험하면 밤새 서버를 뒤진다.

**숨긴 것**
- 예전에 편집국에서 "이음매 감지" 시스템을 만들던 엔지니어였다. 편집국이 그 기술을 이음매를 **숨기는** 데 쓰는 걸 알고 도망쳤다.

**게임에서의 역할**: 컷 배열 퍼즐의 3단계 힌트 담당(시스템 문서 참고). 가짜 컷 파트에서는 "돋보기 분석" 도구를 제공한다.

### 🕯️ 아이자와 시오리 (相沢 栞) — 레이에게만 보이는 소녀
| 항목 | 내용 |
|---|---|
| 나이 | 16 (외형) |
| 정체 | 6년 전 화재로 죽은 레이의 소꿉친구. 정확히는 **레이의 기억 속 그녀의 컷** |
| 외형 | 옛 교복(세일러), 긴 흑발, 앞머리에 책갈피 모양 머리핀. 윤곽이 스크린톤처럼 반투명. 맨발. |
| 테마 색 | 바랜 종이색 + 잉크 검정 |
| 말버릇 | 말을 거의 하지 않는다. 컷 하나를 가리키고 사라진다. 대사가 있을 때는 말풍선이 손글씨체. |

**역할**
- 매 장 현장에 한 번씩 나타나 **핵심 컷**을 가리킨다. (게임의 최종 힌트 역할 + 복선)
- 레이 외에는 아무도 못 본다. 레이는 처음에 피로로 인한 환각이라고 생각한다.
- 장이 진행될수록 대사가 조금씩 늘어나고, 윤곽이 선명해진다.

**과거**
- 이야기를 쓰는 아이였다. 레이가 그림을, 시오리가 글을 맡아 함께 만화를 만들었다.
- 둘의 아지트는 폐관이 결정된 등대 도서관. 콘테스트 투고용 원고를 거기서 그렸다.
- 원고의 마지막 페이지는 **비어 있었다.** "결말은 같이 정하자"고 했으니까.

### 🎭 카미시로 렌 (神代 蓮) — 라이벌, 편집자
| 항목 | 내용 |
|---|---|
| 나이 | 24 |
| 소속 | 편집국 소속 편집자 |
| 겉 속성 | 중2병 귀족풍, 미소년 라이벌 |
| 외형 | 은발 반묶음, 왼쪽 눈 검은 안대, 흰 장갑, 하얀 롱코트. 말할 때 손짓이 과장됨. 안대 아래는 멀쩡하다(이유는 후술). |
| 테마 색 | 순백 + 수정펜 하늘색 |
| 말버릇 | "아름답지 않은 컷은 지워야지." / "읽기만 하는 자, 시노노메." |

**성격**
- 연극적이고 오만하다. 그러나 행동 원리는 일관되게 **"고통을 지워주는 것"**.
- 레이를 라이벌로 부르며 집착한다.

**숨긴 것**
- 6년 전 18살 견습 편집자로 화재 현장의 잔상을 지우는 일에 투입되었다.
- 그날 밤 병원에서 깨어난 16살 레이가 "이 하루를 지워 달라"고 울며 매달렸다. 렌은 그 부탁을 들어줬다. **렌의 첫 독자적 편집.**
- 그러나 견습의 편집은 불완전했다. 레이의 기억은 지워진 게 아니라 **순서가 뒤섞인 채 묻혔고**, 레이에게는 이유 모를 죄책감만 남았다.
- 안대는 그날의 실패를 잊지 않겠다는 본인만의 표식(중2병의 외피를 쓴 죄책감).

**아크**
구원이라 믿었던 편집이 사실은 한 사람을 6년간 가둬두었다는 걸 인정하는 이야기. 진실 엔딩에서 편집국을 고발하는 증인이 된다.

**최종 대립**
악당이라기보다 **"다른 결론을 낸 어른"**. 5장에서 레이에게 마지막 편집을 제안한다: "다시 잊게 해줄게. 이번엔 완벽하게."
