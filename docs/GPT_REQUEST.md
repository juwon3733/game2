# GPT 그림 요청 (10/26 리뷰 반영 후)

전체 284장 중 없는 그림 205장 + 다시 받을 그림 37장. 아래 글을 GPT(이미지 에이전트)에게 그대로 보낸다.

```
최신 main을 받고 docs/GPT_QUEUE.md(작업 순서표)만 보고 1번부터 차례로 해.

시작 전에
- 닫힌 assets PR 중 가장 최근 것에 달린 검수 코멘트를 읽어. 거기서 지적된 실수는 다시 하지 마.

만들 때 (한 줄 = 한 장)
- 표에 없는 그림은 만들지 마. 설정화도 만들지 마.
- 프롬프트는 web/assets/prompts.json에서 같은 id의 prompt를 한 글자도 고치지 말고 그대로 써.
- 「첨부」 칸의 PNG를 반드시 이미지로 붙여. 그 인물은 첨부 그림과 같은 얼굴·머리색·옷·나이로.
- 「확인」 칸은 그 장에서 틀리기 쉬운 것이야. 그리기 전에 읽고, 다 그린 뒤 하나씩 맞는지 봐.
- 프롬프트에 없는 사람은 절대 그리지 마. first-person이면 보는 사람은 손·발만.
- RIGHT/LEFT는 그림 속 인물 자신의 오른쪽/왼쪽이야. 정면을 보는 인물의 오른쪽 리본은 화면 왼쪽에 보여. 좌우만 틀렸고 그림에 글자가 없으면 좌우 반전으로 고쳐도 돼.
- 시계가 나오면 적힌 시각과 정확히 같게. "No clock"이면 시계·손목시계를 하나도 그리지 마.

올리기 전에 (한 장마다)
- 그림을 손바닥만 하게 줄여 놓고 「꼭 보여야 할 것」을 하나씩 찾아. 하나라도 없거나 안 보이면 다시 만들어(최대 3번).
- 첨부 그림과 나란히 놓고 같은 사람인지 확인해.
- PR 설명에 장마다 한 줄: "id — 꼭 보여야 할 것이 그림 어디에 있는지"(예: 3G — 시계 오른쪽 위 9:15, 붕대 발목 왼쪽 아래). 못 맞춘 건 솔직히 적어.

올리기
- 표의 ## 묶음마다 PR 하나, 12장이 넘으면 12장씩 나눠. 브랜치는 assets/<첫 id>-<월일시분>, 늘 새 이름. 겹치면 조사하지 말고 시각만 바꿔 다시 푸시.
- 그림 파일 말고 다른 파일은 건드리지 마.
- PR 올리면 기다리지 말고 다음 줄로. 끝까지 하면 "끝"이라고만 말해.
```
