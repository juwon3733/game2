# GPT 그림 요청 (10/26 리뷰 반영 후)

전체 284장 중 없는 그림 205장 + 다시 받을 그림 37장. 아래 글을 GPT(이미지 에이전트)에게 그대로 보낸다.

```
최신 main을 받고 docs/GPT_QUEUE.md를 봐. 새 그림은 다 끝났고 이제 「다시 받기」 표만 남았어. 1번부터 차례로 해.

- 각 줄의 「할 일」에 적힌 이유를 고치는 게 목적이야. 그게 안 고쳐졌으면 다시 만들어(최대 3번).
- 상반신(portraits)은 지금 그림을 조금 고치지 말고 새로 그려. 지난번엔 거의 같은 그림이 왔어. 옷·소품·색은 지금 그림과 같게, 적힌 것(나이·복장·자세)만 확실히 달라야 해.
- 「첨부」 칸의 PNG를 이미지로 붙이고, 프롬프트는 web/assets/prompts.json의 같은 id prompt를 그대로 써. 수정 사유는 이제 프롬프트 원문에 들어가 있어. 「할 일」 칸 이유를 덧붙여 써도 돼.
- 사람 없는 장면에 사람을 그리지 마. first-person이면 보는 사람은 손·발만.
- 다 만든 뒤 「꼭 보여야 할 것」과 「할 일」 이유를 하나씩 확인하고, PR 설명에 장마다 "id — 고친 것 / 못 고친 것" 한 줄.
- PR 하나로 올려. 브랜치는 assets/redo-<월일시분>. 그림 파일 말고 다른 파일은 건드리지 마. 끝나면 "끝"이라고만 말해.
```
