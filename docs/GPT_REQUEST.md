# GPT 그림 요청 (10/26 리뷰 반영 후)

전체 284장 중 없는 그림 205장 + 다시 받을 그림 37장. 아래 글을 GPT(이미지 에이전트)에게 그대로 보낸다.

```
최신 main을 받아. 그다음 docs/GPT_QUEUE.md(작업 순서표)만 보고 그대로 해.
- 표의 1번부터 순서대로, 한 줄 = 한 장. 표에 없는 그림은 만들지 마.
- 프롬프트는 web/assets/prompts.json에서 같은 id의 prompt를 고치지 말고 그대로.
- 설정화는 절대 만들지 마. 「첨부」 칸의 PNG를 이미지로 붙여서 그려.
- 다 그리면 첨부한 그림과 같은 사람·나이인지, 「꼭 보여야 할 것」이 보이는지 보고, 아니면 다시(최대 3번).
- 「다시」 줄은 적힌 이유를 고치는 게 목적. PR 설명에 고쳤는지 한 줄.
- 표의 ## 묶음마다 PR 하나. 브랜치는 assets/<첫 id>-<월일시분>(늘 새 이름, 겹치면 조사하지 말고 시각만 바꿔 다시 푸시).
- PR 올리면 기다리지 말고 다음 줄로. 끝까지 하면 "끝"이라고만 말해.
```
