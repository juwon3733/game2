# GPT 그림 요청 (10/26 리뷰 반영 후)

전체 284장 중 없는 그림 205장 + 다시 받을 그림 37장. 아래 글을 GPT(이미지 에이전트)에게 그대로 보낸다.

```
최신 main을 받고 docs/GPT_QUEUE.md(작업 순서표)만 보고 1번부터 차례로 해.

진행 방식 (중요)
- 지금은 "남은 그림 다 뽑기"가 먼저야. 한 장당 한 번만 만들고 바로 다음 줄로 가. 다시 뽑지 마.
- 「꼭 보여야 할 것」이 빠졌거나 사람이 하나 더 나왔어도 그대로 올리고, PR 설명에 "id — 빠진 것"만 한 줄 적어. 고치는 건 내가 보고 마지막 「다시 받기」 표에 넣는다.
- 맨 아래 「다시 받기」 표는 새 그림을 전부 올린 뒤에 해. 거기서는 적힌 이유를 고치는 게 목적이라 최대 2번까지 다시 만들어도 돼.
- 이미지 도구가 거절하거나 오류가 나면 그 줄은 건너뛰고 PR 설명에 적어.

만들 때
- 표에 없는 그림은 만들지 마. 설정화도 만들지 마.
- 프롬프트는 web/assets/prompts.json에서 같은 id의 prompt를 한 글자도 고치지 말고 그대로 써.
- 「첨부」 칸의 PNG를 반드시 이미지로 붙여. 그 인물은 첨부 그림과 같은 얼굴·머리색·옷·나이로.
- 「확인」 칸을 그리기 전에 읽어.
- 프롬프트에 없는 인물은 그리지 마. 컷이 바깥·공공장소면 멀리 작은 얼굴 없는 행인은 괜찮아. 배경(bg)은 사람 없이. first-person이면 보는 사람은 손·발만.
- RIGHT/LEFT는 그림 속 인물 자신의 오른쪽/왼쪽이야. 좌우만 틀렸고 글자가 없으면 좌우 반전으로 고쳐도 돼(다시 뽑는 게 아니니 괜찮아).

올리기
- 표의 ## 묶음마다 PR 하나, 12장이 넘으면 12장씩 나눠. 브랜치는 assets/<첫 id>-<월일시분>, 늘 새 이름. 겹치면 조사하지 말고 시각만 바꿔 다시 푸시.
- 그림 파일 말고 다른 파일은 건드리지 마.
- PR 올리면 기다리지 말고 다음 줄로. 끝까지 하면 "끝"이라고만 말해.
```
