- 여성 6, 남성 2. 나이·체형·분위기를 넓게: 쌍둥이(어림) ~ 노신사(노년), 장신 근육질부터 작은 체구까지.
- **미성년(미미·모모)은 단정한 옷.** 성인 여성은 가챠풍으로 몸에 맞는 옷·어깨·다리 노출까지(노골적인 건 없음).
- 여성 캐릭터는 대부분 장발.

카드 표 읽는 법: 비용 `1` = 에너지 1, `시간` = 밤 시계 30분. 강화판은 괄호.

## 미미·모모 — 쌍둥이 (해금)
- **겉모습**: 열두 살 쌍둥이. 미미는 분홍 단발에 오른쪽 리본, 모모는 하늘색 단발에 왼쪽 리본. 거울처럼 대칭인 단정한 세일러풍 원피스, 각자 작은 단검과 우산. **미성년: 단정하게.**
- **키워드 쌍**: 카드가 「미미」 카드와 「모모」 카드로 나뉜다. 둘은 연계에서 **서로 다른 동료로 친다**(쌍둥이끼리 번갈아 써도 연계가 참). 직전 카드가 반대쪽 쌍둥이 카드면 **쌍** 효과가 붙는다.
- **말투**: 둘이 말을 나눠서 함. "미미가 먼저!" "…모모가 마무리."

| 노엘+시온 | 꿈속 별자리 | 정령 2, 마력 +2 |
| 노엘+세바스 | 모닝콜 | 마력 2배, 깨어나지 않고 「별똥 마법」 1장 얻음 |
| 레이븐+미미·모모 | 숨은 칼 | 독 5, 피해 4를 두 번 |
| 레이븐+시온 | 검은 별 | 정령마다 모든 적 독 3 |
| 레이븐+세바스 | 독이 든 홍차 | 독 10, 약화 2 |
| 미미·모모+시온 | 별 보는 밤 | 정령 1, 연계 +1, 카드 1장 |
| 미미·모모+세바스 | 집사와 쌍둥이 | 카드 3장, 에너지 1 |
| 시온+세바스 | 별의 시간 | 밤 시계 15분 되돌리기, 정령 1 |

## 휴식 칸 대화 예시
- 아이리스·브릭: 브릭 "또 혼자 앞서 나가지 마!" / 아이리스 "…네 포탄이 늦은 거다."
- 마르타·노엘: 노엘이 마르타 무릎을 베고 잠듦. 마르타 "5분만이에요."
- 레이븐·세바스: 세바스 "차에 독은 안 넣었습니다." / 레이븐 "…그 말이 더 무섭군."
- 시온·미미·모모: 미미 "저 별 이름 뭐야?" 모모 "…시온 언니, 또 길어진다."

짝마다 2~3개, 듀오를 찾은 짝에게 우선. 대사 말투는 각 동료 말투 줄을 따른다.
