# 05. 판 바깥 (해금·기록·난이도)

## 별 조각
판이 끝나면(이기든 지든) 받는다.
| 얻는 곳 | 별 조각 |
|---|---|
| 막 보스 격파 | 막마다 10 |
| 「새벽」 격파 | 20 |
| 도착 시각 보너스 | 6:00 전 10분마다 +2 (최대 +20) |
| 새로 찾은 듀오 | 쌍마다 5 (처음 한 번) |
| 강적 격파 | 3 |
| 패배 | 도달한 층 수 ×1 |

## 해금 (야경단 본부 화면)
본부는 탑 아래 등대 같은 건물. 메뉴 하나에 해금 목록이 있다.
| 해금 | 별 조각 | 내용 |
|---|---|---|
| 미미·모모 | 40 | 동료 |
| 시온 | 60 | 동료 |
| 세바스 | 80 | 동료 |
| 동료별 카드 묶음 1·2 | 15씩 | 그 동료 보상 풀에 카드 2장 추가 (위 표의 아래쪽 카드들은 처음엔 잠김) |
| 도구 묶음 | 20씩 | 도구 4개씩 등장 풀에 추가 |
| 시작 도구 고르기 | 30 | 판 시작에 시작 도구 3개 중 1개 |
| 달 고르기 | 50 | 판 시작에 달 모양을 고름 |
| 동료 의상 | 30씩 | 동료마다 두 번째 의상(그림 1장) |

- 처음 몇 판 만에 첫 해금이 되도록, 첫 판은 져도 최소 15 정도가 들어오게 한다.
- 가챠·현금 없음.

## 도감
- **동료**: 동료 그림, 말투 한 줄, 쓴 판 수, 이긴 판 수
- **듀오**: 28칸. 찾은 듀오는 컷인을 다시 볼 수 있음
- **카드**: 본 카드 / 쓴 카드
- **적**: 만난 적, 이긴 적
- **휴식 대화**: 본 대화 다시 보기

## 기록
- 동료 조합별 최고 도착 시각
- 달별 승리 횟수
- 「밤의 깊이」 최고 단계

## 난이도: 밤의 깊이
「새벽」을 한 번 이기면 열린다. 단계는 누적.
| 단계 | 추가 규칙 |
|---|---|
| 1 | 강적 체력 +15% |
| 2 | 칸 시간 +5분 |
| 3 | 시작 체력 -10 |
| 4 | 보스 체력 +15% |
| 5 | 낮잠이 20분만 되찾음 |
| 6 | 시작 덱에 저주 「졸음」 1장 |
| 7 | 일반 적 체력 +10% |
| 8 | 여명 효과가 5:30부터 |
| 9 | 휴식 회복 20% |
| 10 | 「새벽」이 매 턴 +15분 |

## 매일의 밤 (나중에)
- 날짜를 시드로 지도·달·보상이 정해진 판. 모두 같은 판을 한다(온라인 순위는 없이, 자기 기록만).
