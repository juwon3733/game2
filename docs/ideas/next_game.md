# 다음 게임 후보 (킵)

이 게임(「같은 하루, 다른 칸」)과는 별개 프로젝트. 정해지면 새 레포로 옮긴다.

## 기준
- 반복 루프가 있을 것 (뽑은 캐릭터를 계속 쓸 판)
- 멈춘 그림으로 될 것 (상반신·카드·컷인. 걷는 도트·애니메이션 없이)
- 캐릭터가 크게, 자주 보일 것. 캐릭터 다양하게(역할·분위기·체형·나이), 여성 비중 높게
- 가챠 있음 (현금 없음, 플레이로 재화)

## 킵 1: 「야경단」 — 덱빌딩 로그라이크 + 캐릭터 가챠
- 설정: 매일 밤 0시 바다 위에 탑이 솟고, 해 뜨기 전 꼭대기에 닿아야 도시가 아침을 맞는다. 탑에서 떨어지는 별 조각으로 동료를 부른다(가챠). 한 판 = 하룻밤.
- 루프: 파티 3명 → 층마다 길 고르기(전투/상점/이벤트/휴식) → 카드·유물 → 보스 → 별 조각 → 가챠 → 다음 판.
- 캐릭터마다 자기 카드 묶음. 새 캐릭터 = 새 조합.
- 가챠: ★3/★4/★5, 50번 천장, 겹치면 각성(카드 강화 + 새 의상). 조합 핵심 ★3도 둔다. 캐릭터별 호감도 대화.
- 역할 축: 공격 / 방어 / 독·화상 / 드로우 / 소환.
- 시작 8명(여성 5) → 업데이트마다 2명.
- 그림: 1명당 상반신 3 + 컷인 1 + 각성 의상 1 + 카드 5~6 ≈ 10장.
- 첫 단계: 임시 그림으로 한 판 도는 프로토타입(전투·탑 지도·가챠 화면).

## 탈락
- 경영 시뮬(작은 걷는 도트 필요), 레인 카드 배틀(AI 상대만으론 금방 질림), 격투 분석관(추리 빼기로 함).

## 킵 2: 「빙의」 — 내 몸 하나, 영혼 여럿
- 주인공은 빈 그릇 같은 사람. 가챠로 뽑는 건 떠도는 영혼(전설의 검객, 몰락한 여왕, 전쟁 영웅 등).
- 전투 중 영혼을 갈아 끼우면 주인공 겉모습이 그 사람으로 바뀌는 변신 컷인.
- 영혼들끼리 주인공 머릿속에서 말다툼하는 장면이 이야기의 재미.
- 그림: 영혼 본인 모습 + 주인공이 빙의한 모습(영혼마다 2벌).

## 킵 3: 「그림자 결투」 — 빛을 움직여 그림자로 싸운다
- 캐릭터는 직접 싸우지 않고 그림자가 싸운다. 플레이어가 움직이는 건 빛(가로등·달·횃불)의 위치.
- 빛을 낮추면 그림자가 길게 뻗어 먼 적의 그림자를 베고, 머리 위로 올리면 짧아져 숨는다.
- 캐릭터는 예쁘게 서 있고, 그림자는 숨겨진 간지 버전 실루엣(가녀린 소녀의 그림자가 거대한 낫을 든 형태 등).
- 그림: 캐릭터 1장 + 그림자 실루엣 1장. 그림자 길이·방향은 코드로 늘이고 기울임.

## 킵 4: 「30초 4회차」 — 혼자 하는 4인 레이드
- 보스전 30초. 1회차는 캐릭터 A로 싸우고, 되감기면 B로 다시 싸운다. 이때 A는 1회차 행동을 그대로 반복한다.
- 4회차에는 앞의 세 번 행동이 모두 겹쳐 4인 합동 공격이 완성된다.
- "A가 보스를 띄울 때 B가 거기 있어야 한다"를 미리 계산하는 퍼즐 + 액션. 마지막 회차에 넷이 맞물리는 순간이 쾌감.
- 캐릭터 넷의 역할이 서로 맞물려야 이기므로 개성이 곧 놀이.

## 그 밖에 나온 후보 (보류)
- 현상수배: 가챠 = 수배서 → 추적 → 대결 → 동료로 들이기.
- 듀오: 2인 1조, 짝마다 다른 합동 필살기. 모으는 건 관계.
- 캐스팅: 가챠 = 오디션, 한 판 = 장르 영화 한 편, 끝에 포스터.
- 실 잇기: 캐릭터 사이 실로 그물을 만들어 적을 자름. 짝마다 실 성질이 다름.
- 종이 접기 전장: 종이를 접어 먼 칸을 겹치는 공간 전술.

## 사용자 취향 메모
- 이야기·관찰·돌보기 위주 싫음. 판 자체가 재미있는 놀이 + 예쁜/간지 캐릭터.
- 기존 장르를 빌린 것(발라트로식, 체스, 육성 등)은 "독창적이지 않다". 조작 방식 자체가 새로워야 함.
- 가챠는 없어도 됨.
