# 다음 게임 후보 (킵)

이 게임(「같은 하루, 다른 칸」)과는 별개 프로젝트. 정해지면 새 레포로 옮긴다.

## 기준
- 반복 루프가 있을 것 (뽑은 캐릭터를 계속 쓸 판)
- 멈춘 그림으로 될 것 (상반신·카드·컷인. 걷는 도트·애니메이션 없이)
- 캐릭터가 크게, 자주 보일 것. 캐릭터 다양하게(역할·분위기·체형·나이), 여성 비중 높게
- 가챠 있음 (현금 없음, 플레이로 재화)

## 킵 1: 「야경단」 — 덱빌딩 로그라이크 + 캐릭터 가챠
- 설정: 매일 밤 0시 바다 위에 탑이 솟고, 해 뜨기 전 꼭대기에 닿아야 도시가 아침을 맞는다. 탑에서 떨어지는 별 조각으로 동료를 부른다(가챠). 한 판 = 하룻밤.
- 루프: 파티 3명 → 층마다 길 고르기(전투/상점/이벤트/휴식) → 카드·유물 → 보스 → 별 조각 → 가챠 → 다음 판.
- 캐릭터마다 자기 카드 묶음. 새 캐릭터 = 새 조합.
- 가챠: ★3/★4/★5, 50번 천장, 겹치면 각성(카드 강화 + 새 의상). 조합 핵심 ★3도 둔다. 캐릭터별 호감도 대화.
- 역할 축: 공격 / 방어 / 독·화상 / 드로우 / 소환.
- 시작 8명(여성 5) → 업데이트마다 2명.
- 그림: 1명당 상반신 3 + 컷인 1 + 각성 의상 1 + 카드 5~6 ≈ 10장.
- 첫 단계: 임시 그림으로 한 판 도는 프로토타입(전투·탑 지도·가챠 화면).

## 탈락
- 경영 시뮬(작은 걷는 도트 필요), 레인 카드 배틀(AI 상대만으론 금방 질림), 격투 분석관(추리 빼기로 함).
