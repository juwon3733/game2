# 04. 게임 시스템

## 1. 장(章) 단위 게임 루프

```
브리핑 ─▶ 현장 조사 ─▶ 컷 배열 ─▶ 심문 ─▶ 추가 조사 ─▶ 최종 재구성 ─▶ 결론 제시 ─▶ 에필로그
 (사무실)   (탐색)      (퍼즐)    (대화)    (탐색)       (대형 퍼즐)     (선택)      (카페 「여백」)
                ▲                     │
                └──── 새 컷 / 새 장소 ──┘   ← 심문에서 열린 컷이 다시 탐색과 배열로 이어짐
```

| 단계 | 내용 | 1장 기준 소요 |
|---|---|---|
| 브리핑 | 잔상과 사무실. 사건 개요, 반장의 지시, 코하루와 토와의 잡담 | 3분 |
| 현장 조사 | 탑뷰 이동. 물건을 조사해 컷 수집. 사람과 대화해 정보 수집 | 10분 |
| 컷 배열 | 원고지에 컷을 시간 순서로 배치 | 5~10분 |
| 심문 | 증인의 증언 페이지에 내 컷을 끼워 반박 | 10분 |
| 추가 조사 | 새로 열린 장소/물건에서 컷 수집 | 5분 |
| 최종 재구성 | 그 장의 진상을 담은 큰 페이지(6~12칸) 완성 | 10~15분 |
| 결론 제시 | "이 사건의 진상은?" 3~4개 질문에 컷으로 답함 | 5분 |
| 에필로그 | 카페 「여백」에서 정리. 다음 장 복선. 시오리 등장 | 3분 |

---

## 2. 현장 조사 (탐색)

- **시점**: 탑뷰 2D, 4방향 이동. 한 사건당 장소 2~4개, 장소당 화면 1~2개.
- **조사 가능 오브젝트**: 반짝임 없이 커서를 올리면 테두리가 생긴다. (픽셀 헌팅 방지를 위해 "레이의 감각" 키를 누르면 주변 잔상이 남은 물건이 잠깐 잔물결처럼 빛남)
- **잔상 읽기 연출**: 물건 조사 → 화면이 스크린톤으로 덮임 → 원고지 한 장이 날아와 컷이 그려지는 애니메이션(0.8초, 스킵 가능) → 컷 보관함에 추가.
- **일반 조사**: 잔상이 없는 물건은 레이의 짧은 코멘트. 일부는 물증(사건 수첩 메모)으로 기록된다.
- **대화**: NPC와 대화하면 사건 수첩의 "인물" 탭이 갱신된다. 심문 전 사전 정보 수집.

### 사건 수첩 (메뉴)
| 탭 | 내용 |
|---|---|
| 컷 보관함 | 수집한 모든 컷. 시점 주인, 장소로 필터. 확대 보기 |
| 인물 | 인물 초상, 프로필, 알게 된 사실 (새 정보는 밑줄) |
| 메모 | 물증과 키워드. 결론 제시 때 사용 |
| 원고 | 완성한 페이지 다시 보기 |

## 3. 컷 배열 퍼즐 (메인 퍼즐)

### 기본 규칙
- 화면 왼쪽: 빈 원고지 (칸 수 고정, 4 / 6 / 9 / 12칸)
- 화면 오른쪽: 이번 페이지에 쓸 컷 묶음
- 컷을 드래그해서 칸에 놓는다. 읽는 방향은 만화와 같이 **오른쪽 위 → 왼쪽 아래**가 아니라, 국내 독자 기준 **왼쪽 위 → 오른쪽 아래**. (설정에서 일본식 읽기 방향 선택 가능)
- 모든 칸을 채우고 **[페이지 넘기기]** 를 누르면 판정.

### 단서의 종류 (컷 안에서 읽어야 하는 것)

| 단서 | 예시 | 사용하는 장 |
|---|---|---|
| 소품 상태 | 머리핀이 있다/없다, 컵의 커피 양, 우산이 젖음 | 전체 |
| 빛과 하늘 | 노을 → 밤, 달이 구름에 가려짐, 가로등 켜짐 | 전체 |
| 그림자 | 길이와 방향 | 3장 이후 |
| 소리 | 의성어 (피아노 ♪, 쿵, 쏴아) | 1장 |
| 조명 색 | 라이브 곡마다 다른 무대 조명 색 | 2장 |
| 상처/얼룩 | 넘어진 뒤 무릎의 상처, 옷에 묻은 페인트 | 2~3장 |
| 화면 속 화면 | 벽 시계, 휴대폰 배터리 표시, TV 야구 중계 이닝 | 1장, 4장 |

> 설계 원칙: **모든 정답 배열은 컷 안의 시각 정보만으로 유일하게 결정되어야 한다.** 대화 내용을 몰라도 컷만 보고 풀 수 있어야 한다. 대화는 "어디를 봐야 하는지" 힌트를 줄 뿐이다.

### 판정과 피드백
- **정답**: 컷이 차례로 이어지며 말풍선과 효과음이 애니메이션으로 재생됨 → "페이지가 읽힌다" 연출. 마지막 컷에서 레이의 한 줄 독백.
- **오답**: 페이지 전체를 판정하지 않고, **모순이 있는 경계선**만 빨간 지그재그로 떨림. (예: 3번 칸과 4번 칸 사이) 어느 쪽 컷이 틀렸는지는 알려주지 않는다.
- **부분 정답 고정**: 연속으로 맞은 칸은 모서리에 작은 클립이 꽂힌다(선택 옵션, 기본 ON). 오브라 딘의 "3개 맞으면 확정"과 같은 역할.
- **페널티 없음**: 횟수 제한 없음. 다만 장 결과의 "원고 평가"에 시도 횟수가 반영된다.

### 원고 평가
| 등급 | 조건 | 보상 |
|---|---|---|
| 완벽 원고 | 첫 시도 정답 | 갤러리에 레이의 컷 해설 해금 |
| 수정 원고 | 2~3회 | — |
| 초고 | 4회 이상 또는 힌트 3단계 사용 | — |

평가는 스토리에 영향을 주지 않는다. 엔딩 조건과도 무관하다.

### 특수 배열 규칙 (장별로 추가)

| 장 | 규칙 | 설명 |
|---|---|---|
| 1장 | 말풍선 | 빈 말풍선에 대사 조각 붙이기 (아래 4장 참고) |
| 2장 | **동시 컷** | 한 칸이 세로로 둘로 나뉨. 같은 순간을 다른 시점에서 본 컷 두 장을 함께 놓아야 함 |
| 3장 | **동일 얼굴** | 쌍둥이가 나오는 컷은 누구 시점인지 판별해야 함. 컷을 놓기 전에 "유키 / 나기" 라벨을 붙임 |
| 3장~ | **가짜 컷 섞임** | 묶음에 들어갈 자리가 없는 컷이 섞여 있음. 가짜를 찾아 "파기" 칸에 버려야 함 |
| 4장 | **원본 복원** | 편집된 컷의 위층을 벗겨 원본을 꺼낸 뒤 배열 |
| 5장 | **두 줄 타임라인** | 레이의 줄과 시오리의 줄을 나란히 배열. 같은 높이의 칸은 같은 순간이어야 함 |

## 4. 말풍선 퍼즐

- 일부 컷은 말풍선이 비어 있다. 사건 중 들은 **대사 조각**(사건 수첩에 저장됨)을 끌어다 붙인다.
- 말풍선 모양이 단서다.

| 말풍선 모양 | 의미 |
|---|---|
| 둥근 풍선 | 보통 대화 |
| 뾰족한 폭발형 | 외침 |
| 점선 | 속삭임 / 혼잣말 |
| 꼬리 없는 사각형 | 내레이션, 생각 |
| 꼬리가 컷 밖을 향함 | 화면 밖 인물의 말 |

- 같은 대사라도 어느 컷에 붙이느냐에 따라 의미가 바뀌는 경우를 **장마다 최소 하나** 넣는다.
  - 예: "미안, 늦었어." → 사건 전 컷이면 단순 지각, 사건 후 컷이면 알리바이 붕괴.

## 5. 심문

### 구조
1. 증인이 동의하면 **증언 페이지**(증인 시점의 컷 3~6장)가 펼쳐진다.
2. 증언 컷은 증인의 감정에 따라 **왜곡**되어 있다. (02_world.md 왜곡 유형 표 참고)
3. 증인이 컷을 한 장씩 넘기며 증언한다. 각 컷마다 증인의 대사가 붙는다.
4. 플레이어는 두 가지 행동을 할 수 있다.

| 행동 | 조작 | 효과 |
|---|---|---|
| **파고들기** | 현재 컷에서 [?] | 증인이 그 컷을 더 자세히 말함. 새 대사 조각이나 숨은 디테일이 열릴 수 있음. 페널티 없음 |
| **끼워 넣기** | 내 컷 보관함에서 컷을 드래그해 증언 페이지의 칸 사이에 끼움 | 모순을 증명. 맞으면 반박 성공, 틀리면 감정 게이지 하락 |

### 반박 성공 연출
- 내 컷이 증언 페이지에 꽂히면서 화면 가득 효과선과 큰 의성어("탁!").
- 레이: "…순서가 틀렸어."
- 증인 컷의 왜곡 레이어가 **찢어지듯 벗겨지며** 원래 그림이 드러난다.
- 왜곡이 벗겨질 때 새 컷이 보관함에 추가된다.

### 감정 게이지 (증인의 마음)
- 증인마다 하트가 아닌 **잉크병** 3칸. 엉뚱한 컷을 끼우면 1칸 줄어든다.
- 0이 되면 증인이 마음을 닫는다 → 심문 처음부터 재시작 (게임 오버 아님, 대사만 짧게 바뀜).
- **코하루 개입**: 장당 2회. 잉크가 1칸 남았을 때 쓸 수 있다. 코하루가 증인을 달래 잉크 1칸 회복 + 증인이 신경 쓰는 컷 하나에 밑줄 힌트.

### 심문 단계 구성 (장마다)
| 장 | 심문 수 | 최종 심문 특징 |
|---|---|---|
| 1장 | 3 (오오쿠보, 타이가, 히마리) | 아이 증인. 끼워 넣기 대신 **말풍선 붙이기**로 마음을 엶 |
| 2장 | 4 | 3명 동시 증언 (멤버들). 서로의 증언 페이지가 엇갈림 |
| 3장 | 3 | 쌍둥이가 번갈아 증언. 누가 말하는지 판별 |
| 4장 | 2 | 렌과의 대결. 렌이 실시간으로 컷을 고쳐 그림 → 플레이어가 이음매를 지적 |
| 5장 | 2 | 아사기리, 그리고 레이 자신 |

## 6. 가짜 컷 (편집 판별)

3장부터 편집된 컷이 섞인다.

### 이음매 유형 (도트 단위로 설계)
| 이음매 | 보이는 방식 | 난이도 |
|---|---|---|
| 스크린톤 어긋남 | 같은 면의 디더 패턴이 중간에 끊김 | 쉬움 |
| 그림자 방향 | 한 인물의 그림자만 다른 방향 | 쉬움 |
| 선 굵기 | 덧그린 부분만 외곽선이 1px 얇음 | 보통 |
| 복붙 배경 | 군중이나 나뭇잎 패턴이 똑같이 반복 | 보통 |
| 색온도 | 덧그린 인물만 다른 시간대 팔레트 | 보통 |
| 반사 불일치 | 유리/물웅덩이에 비친 모습이 다름 | 어려움 |
| 시점 불가능 | 시점 주인이 볼 수 없는 각도의 장면 | 어려움 (논리형) |

### 조작
- **돋보기 모드**: 컷을 크게 확대해 픽셀 단위로 본다. (토와가 3장에서 제공)
- 이음매라고 생각하는 곳을 클릭 → 맞으면 그 부분에 수정펜 자국이 드러나고 컷에 "편집됨" 도장.
- 틀린 곳을 클릭해도 페널티 없음(오클릭 남발 방지를 위해 3회 연속 오답 시 3초 쿨다운).

### 원본 복원 (4장)
- "편집됨" 도장이 찍힌 컷은 위층을 **긁어서 벗길** 수 있다(마우스 드래그 / 터치 문지르기).
- 벗기면 아래에 원래 컷이 나온다. 원본은 대개 진상의 결정적 장면.

## 7. 결론 제시

장의 마지막. 레이가 반장, 관계자들 앞에서 진상을 정리한다.

- 질문 3~4개가 순서대로 나온다. 예: "사에키 씨는 왜 베란다 난간에 있었나?"
- 답은 **완성한 페이지의 컷 하나를 지목**하거나, **메모의 키워드**를 고르는 방식.
- 틀려도 다시 고를 수 있다. 연출만 약간 바뀐다(반장의 한숨).
- 마지막 질문은 항상 감정적 질문. 예: "히마리에게 무슨 말을 할까?" → 선택지 3개, 정답 없음. 선택에 따라 에필로그 대사와 **여백 컷** 획득 여부가 갈린다.

## 8. 힌트 시스템

컷 배열 퍼즐에서 막혔을 때.

| 단계 | 제공자 | 내용 |
|---|---|---|
| 1단계 | 토와 | "어디를 봐야 하는지" — 단서 종류만 말해줌. "소품 상태를 비교해 봐." |
| 2단계 | 토와 | 단서가 있는 컷 두 장을 하이라이트. "이 두 장에 같은 물건이 있지?" |
| 3단계 | 토와 | 컷 하나의 정확한 위치를 알려줌 |
| 특수 | 시오리 | 장마다 1회 자동 등장. 가장 중요한 컷 하나를 손가락으로 가리킴. 힌트이자 스토리 이벤트 |

힌트 사용은 원고 평가에만 영향. 설정에서 힌트 버튼 자체를 숨길 수 있다.

## 9. 수집 요소: 여백 컷

- 각 장에 하나씩, **아무것도 그려지지 않은 흰 컷**이 숨어 있다.
- 획득 조건: 장마다 다름. 대부분 결론 제시의 마지막 감정 선택 + 특정 오브젝트 조사.
- 여백 컷을 열면 시오리의 짧은 회상(레이와 만화를 그리던 기억 조각)이 나온다.
- 5개 모두 모으면 진 엔딩 「여백」 루트가 열린다. (05_story.md 참고)

| 장 | 여백 컷 위치 (예시) |
|---|---|
| 1장 | 히마리에게 "선생님은 너를 지키고 싶었던 거야"를 고르고, 미츠루의 피아노 악보 마지막 페이지 조사 |
| 2장 | 루루에게 앙코르를 부탁하는 선택 + 무대 뒤 매니저의 수첩 |
| 3장 | 쌍둥이에게 "둘 다 너희야"를 고르고, 유키의 스케치북 |
| 4장 | 렌을 공격하지 않는 선택 + 렌의 안대 |
| 5장 | 앞 4개를 모두 가졌을 때 자동 |

  "state": {                           // 순서 판정용 상태 태그
    "himari_hairpin": "off",

### 순서 판정 방식
- 정답 배열은 장 데이터에 명시 (`"solution": ["c1_a", "c1_b", ...]`).
- 오답 시 어디에 모순 표시를 할지는 **상태 태그의 전이 규칙**으로 계산한다.
  - 예: `himari_hairpin: on → off`는 가능, `off → on`은 불가능 → 해당 경계에 빨간 표시.
  - 상태 규칙으로 잡히지 않는 오답은 정답과 처음으로 달라진 경계에 표시.
- 이렇게 하면 "왜 틀렸는지" 피드백이 컷 내용과 일치한다.
