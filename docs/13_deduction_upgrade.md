## 2. 추가할 추리 시스템

장마다 하나씩 늘리는 게 아니라, **아래 다섯 개를 2장부터 기본으로 쓰고 1장에서 가볍게 익힌다.**

### 2-1. 단서 짚기 (컷 속 세부를 직접 찾기)

- 컷을 크게 보면 그림 위를 눌러 **세부를 짚을 수 있다** (시계, 상자, 머리핀, 반창고, 무늬…).
- 맞는 곳을 짚으면 **단어 조각**을 얻는다: `「꺼진 휴대폰」`, `「21:26」`, `「왼손」`.
- 아무 데나 누르면 반응 없음(벌점 없음). 단서가 그림에 있다는 걸 플레이어가 **스스로 발견**하게 한다.
- 구현: 컷마다 `spots: [{x, y, r, word}]` (그림 기준 비율 좌표). 그림이 들어오면 Claude가 좌표를 찍는다.

### 2-2. 네임 (가설 문장 짜기) — 핵심 시스템

만화 원고 전 단계인 **네임(콘티)** 을 쓰는 화면. 결론과 중간 추리를 이걸로 한다.

```
[ 사에키 미츠루 ] 는 [ 히마리 ] 가 [ 난간 ] 에 오른 것을 보고
[ 칸막이 틈 ] 으로 손을 뻗어 [ 끌어당겼다 ].
그 반동으로 [ 떨어졌다 ]. 그때 [ 반도 타이가 ] 는 [ 5층 현관 앞 ] 에 있었다.
```

- 빈칸에는 **단서 짚기·증언·탐색으로 모은 단어 조각**만 넣을 수 있다. 단어는 정답보다 훨씬 많다(사람 이름 전부, 장소 여럿, 동작 여럿).
- **빈칸이 3개 이상 맞아야** "이 중 N개가 맞다"는 표시가 나온다. 무엇이 맞는지는 알려 주지 않는다 (Golden Idol식).
- 다 맞으면 확정 → 페이지 재생. 틀린 채로 **"이걸로 보고한다"** 도 누를 수 있다 → §2-5 오판.
- 효과: 플레이어가 스스로 가설을 세우고, 단어가 많아서 찍기로는 안 풀린다.

### 2-3. 시각표 (알리바이 계산)

- 퍼즐에 **시각 눈금**이 붙는다 (예: 21:15 ─ 21:30). 컷을 순서뿐 아니라 **시각 칸**에 놓는다.
- 시각 단서는 컷 속에 있다: 벽시계, 휴대폰 시계, TV 야구 이닝, 버스 시간표, 조명 무늬(2장).
- 여러 사람의 시각표를 **나란히** 놓으면 "같은 시각에 두 곳에 있을 수 없다"로 알리바이를 깬다.
- 1장: 오오쿠보 TV의 야구 "9회 말 끝내기"(21:23) ↔ 쿵 소리 시각. 알리바이 개념을 가볍게.

### 2-4. 겹쳐 보기 (두 증거로 반박)

- 반박에 **컷 + 컷**, **컷 + 대사**, **컷 + 물증**을 함께 내야 하는 증언이 생긴다.
- 같은 순간을 다른 시점에서 본 두 컷을 겹치면 한쪽에만 있는 것이 드러난다 (2장 "동시 칸"과 같은 규칙).
- 효과: 한 단서로 풀리는 문제를 없앤다 (§1 #2).

### 2-5. 중간 지목과 오판

- 장 중간에 **"지금까지로 보면 누가 했나?"** 를 네임으로 한 번 쓴다.
- 이때 증거는 **가짜 정답(레드 헤링)을 80%쯤 지지하도록** 설계한다. 대부분의 플레이어가 그 사람을 지목한다.
- 지목하면 이야기가 그대로 진행된다: 그 사람이 연행되거나, 상처받거나, 입을 닫는다. 나중에 진짜 단서가 나오면 **플레이어가 틀렸다는 걸 스스로 깨닫는다.**
- 맞힌 플레이어(소수)에겐 다른 대사와 원고 평가 가산점. 틀린 플레이어도 진행은 막히지 않는다.
- 장 끝 **원고 평가(S~D)**: 오답 수, 힌트 수, 중간 지목 정답 여부. 다시 할 이유가 된다.

### 2-6. 캐릭터가 답을 말하지 않게

- 코하루·토와는 **관찰**("발자국이 작네요")까지만 말하고 **결론**("어린애예요")은 말하지 않는다.
- 결론은 네임이나 반박으로 플레이어가 먼저 내고, 레이가 뒤에 확인해 준다.
- 힌트는 "어디를 보라"까지만. 정답을 직접 고정해 주는 힌트(지금의 2번째 힌트)는 없앤다.

## 3. 스토리: 플레이어를 헷갈리게 하는 설계

### 3-1. 원칙

1. **가짜 정답은 "그럴듯하고 정의로워" 보여야 한다.** 플레이어가 지목하고 싶게. (나쁜 사람처럼 보이는 사람, 숨기는 게 있는 사람)
2. **숨기는 사람 ≠ 범인.** 증인은 각자 다른 이유로 거짓말한다(창피, 누군가를 감쌈, 착각). 거짓말을 깰 때마다 의심이 다른 사람에게 옮겨 간다.
3. **진짜 단서는 처음부터 보이지만 의미가 늦게 붙는다.** 처음 보면 무관해 보이는 세부가 나중에 다른 단서와 겹쳐 뜻이 생긴다.
4. **의심이 장마다 최소 두 번 옮겨 간다.** A → B → 진범 C.
5. **공정성:** 진범을 가리키는 단서는 중간 지목 전에 이미 모두 손에 있어야 한다. 다시 플레이하면 "아, 처음부터 보였네"가 되게.

### 3-2. 1장 「낙하」 다시 짜기 (짧게, 장 길이 +15분)

지금은 "타이가 범인? → 아니다"로 바로 끝난다. **의심을 세 사람에게 돌린다.**

| 단계 | 플레이어가 믿게 되는 것 | 근거(가짜) | 깨는 단서 |
|---|---|---|---|
| 1 | **타이가가 밀었다** | 경비원 증언, 떨어진 상자(몸싸움처럼), 문 앞 발자국, 도망 | 시각표: 쿵 소리 시각에 타이가는 5층 현관 앞(초인종 컷의 ♪ + 오오쿠보 TV의 9회 말) |
| 2 | **히마리가 밀었다 / 히마리 탓이다** | 화분에 찍힌 작은 발자국, 칸막이 아래 틈, 히마리의 "나 때문에", 숨긴 주먹 | 겹쳐 보기: 미츠루 시점 「손을 뻗음」 + 히마리 시점 「끌어당김」 → 미는 손이 아니라 당기는 손 |
| 3 | **(진실) 아무도 밀지 않았다. 구하다가 떨어졌다** | — | 네임 결론 |

- **중간 지목**: 오오쿠보 심문 직후. 증거가 타이가를 가리키도록 둔다 (지금 퍼즐 1은 타이가 무죄를 너무 빨리 보여 주므로, 퍼즐 1에서 「쿵」 컷을 빼고 시각 단서 없이 "초인종 → 피아노 멈춤 → 손을 뻗음"까지만 맞춘다).
  - 타이가를 지목하면: 타이가가 경찰에 끌려가는 장면 + 타이가의 원망 대사. 나중에 무죄가 밝혀질 때 사과 장면이 추가된다.
- **히마리 의심**: 탐색 2의 발자국 + 히마리의 "나 때문에"로 플레이어가 히마리를 의심하게 둔다. 코하루는 "설마 애가…"까지만 말한다.
- **새 단서(정답 쪽)**: 미츠루 집 달력의 "히마리 레슨 → 쉬는 날"(왜 히마리가 그 시간에 베란다에), 레슨 노트의 "음표 머리핀 좋아함"(머리핀이 동기), 화분 흙의 발자국 방향(안쪽 → 난간: 아이 혼자 올라간 흔적).
- **오오쿠보 TV 시각**: 경비실 탐색(맵 추가)에서 TV 편성표를 짚으면 `「9회 말 끝내기 21:23」`.

### 3-3. 2장 「앙코르 없음」 강화

이미 의심이 루루 → 쿠라모치 → 텐도로 옮겨 가게 짜여 있다. 아래를 더한다.

| 추가 | 내용 |
|---|---|
| 중간 지목 = 쿠라모치 | 점검표 서명, "할 말 없어요", 부스에서 리그를 정면으로 보는 위치. 지목하면 쿠라모치가 연행되고 크레센트에서 해고된다. 진실: 텐도가 "말하면 너도 공범"이라고 협박해서 입을 닫았다 |
| 루루를 끝까지 의심하게 | 루루가 캣워크에 오른 컷(진짜)과, 루루의 "내 탓" 거짓 자백. 루루가 리그를 **만진** 건 사실(묶인 걸 확인하려고) |
| 텐도는 처음엔 피해자 편처럼 | 텐도가 레이 팀에 협조적이고, 오히려 쿠라모치를 의심하는 정보를 준다 |
| 시각표 | 곡마다 바뀌는 조명 무늬(별/물결/격자)가 시계 역할. "끈을 풀었다" 시각을 무늬로 고정 |
| 겹쳐 보기 | 부스 쿠라모치 시점 + 캣워크 텐도 시점 → 같은 순간, 텐도 손목의 사각 금시계 |
| 네임 결론 | `[텐도]가 [개장 직전]에 [끈]을 [풀었다]. [키리시마]는 [윙]에서 [루루]를 [밀어냈다]` 등 빈칸 9개 |

### 3-4. 3장 「둘 중 하나」 강화

| 추가 | 내용 |
|---|---|
| 마도카를 아군처럼 | 마도카가 "미래 컷"으로 수사를 돕는 조력자로 등장. 플레이어가 믿게 만든다 |
| 중간 지목 = 유키 | 근무표, 오른쪽 리본, 미래 컷. 지목하면 유키가 입시를 포기하겠다고 한다 |
| 쌍둥이 시점 라벨 | 손(왼손잡이)·발목 반창고를 **단서 짚기**로 찾아야 라벨을 붙일 수 있다 |
| 가짜 컷 | 마도카의 미래 컷 이음매를 돋보기로 짚기 = 마도카 의심의 시작 |

### 3-5. 4·5·종장

- 4장: 중간 지목 = **손녀 하야카**(기억을 지운 사람). 실제로는 엄마를 감싼 것. 그 엄마도 범인이 아님(망을 봤지만 불에 뛰어든 사람).
- 5장: 중간 지목 = **렌**(편집국). 실제 편집장은 아사기리. 1장부터 아사기리 대사에 이음매를 심어 둔다(같은 말 반복: "힘든 건 잊어도 돼").
- 종장: 지목 대상이 **레이 자신**. "나는 도망쳤다"는 자기 증언을 깨는 것이 마지막 추리.

## 4. 제작 순서

| 단계 | 할 일 | 담당 |
|---|---|---|
| 1 | 엔진: 단서 짚기(spots), 네임(가설 문장), 시각표, 겹쳐 보기, 중간 지목·원고 평가 | Claude |
| 2 | 1장에 적용: 퍼즐 1 축소(「쿵」 제외), 중간 지목(타이가), 히마리 의심 단계, 네임 결론, 경비실 탐색 맵, 대사에서 결론 빼기 | Claude |
| 3 | 1장용 새 그림: 경비실 탐색 맵, 타이가 연행 장면 CG, 컷 2~3장(발자국 방향, TV 편성표) | GPT |
| 4 | 1장 플레이 테스트 → 난이도 조정 | 사용자 + Claude |
| 5 | 2장 제작 (모든 시스템 사용) | 둘 다 |

## 5. 정해 줄 것

1. **중간 지목에서 틀리면 이야기가 실제로 바뀌는 것**(타이가 연행, 쿠라모치 해고 등) 괜찮은지. 아니면 "레이의 머릿속 가설"로만 처리할지.
2. **원고 평가(S~D)** 넣을지.
3. 1장을 위처럼 다시 짤지, 1장은 튜토리얼로 두고 2장부터 적용할지.
