# 16. 인물 말투 표

새 대사를 쓸 때 이 표를 따른다. `node tools/lint-text.mjs`가 일부(금지어·조사·반복·주제문)를 자동으로 잡는다.

## 공통 규칙
- 조작 설명은 `say('tip', …)`. 인물은 사건 얘기만.
- "X인 게 아니라 Y인 거야" 같은 주제문은 장마다 하나까지(종장 절정 한 번). 나머지는 장면으로.
- "…"로 시작하는 대사는 레이의 짧은 말·히마리·쿠라모치 정도만.
- 존댓말 상대에게 "당신" 금지 → 이름 + 씨, 직함. "그녀" 금지.
- 3박자 나열(A, B, C.)과 시적 대구는 피한다. 사람이 실제로 하는 말로.
- 방금 화면에 나온 걸 인물이 다시 요약하지 않는다.
