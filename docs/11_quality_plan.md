## 단계별 계획

담당: **GPT** = 이미지 에이전트, **Claude** = 코드·검수, **사용자** = 결정·외부 도구.

### 1단계 — 기본 그림 교체 (진행 중)

| 할 일 | 담당 | 끝난 기준 |
|---|---|---|
| 상반신 v3 16장 (`portrait-*` 9묶음) | GPT | 256×384 도트, 투명, 양옆·위 여백. Claude가 같은 사람으로 보이는지 확인 |
| 탐색 맵 `map` | GPT | 1248×624, 26×13칸 배치 |
| 맵에 충돌 칸·물건 위치 맞추기 | Claude | 벽·가구를 못 지나가고, `!` 표시가 그림 속 물건 위에 뜸 |
| 걷는 캐릭터 `sprite` 3장 | GPT | 3열×4행, 발 높이 일정. 걷기 애니메이션이 튀지 않음 |
| 타이틀 키아트 `title` | GPT | 왼쪽 40% 비움, 글자 없음 |

### 2단계 — UI 스킨 (GPT 이미지)

웹페이지 느낌을 없애는 단계. 9-slice(모서리는 고정, 가운데는 늘어나는) 이미지로 받아 CSS `border-image`로 씌운다.

| 이미지 | 크기(안) | 쓰는 곳 |
|---|---|---|
| 대사창 프레임 | 192×96 (9-slice 24px) | `#textbox` 일반 / 내레이션 2종 |
| 이름표 | 96×32 | 캐릭터별 색은 코드로 덧칠 |
| 버튼 | 96×32 (보통·눌림·강조) | 메뉴, 확정, 힌트 |
| 패널 | 128×128 | 수첩, 모달, 결론 질문 |
| 컷 카드 테두리 | 128×96 | 수첩·퍼즐·결론의 컷 카드 |
| 원고지 바탕 | 768×512 | 퍼즐 칸 배경 |
| 아이콘 묶음 | 32×32 × 8 | 수첩, 돋보기, 증인의 마음, 확인, 닫기, 힌트(토와), 음량, 설정 |
| "반박!" 컷인 | 1536×512 | 심문에서 컷을 들이밀 때 |
| "컷 획득" 연출 프레임 | 1024×768 | 잔상을 얻을 때 |

- Claude: `asset_prompts.js`에 `ui` 종류 추가 → 프롬프트 → 적용. Galmuri 글꼴 파일을 저장소에 넣어 CDN 없이 뜨게 한다.

### 3단계 — 연출 (Claude, 그림 없이 바로 가능)

| 할 일 | 내용 |
|---|---|
| 타자 효과 | 글자가 한 자씩 나옴. 클릭하면 한 번에 다 보이고, 한 번 더 누르면 다음 |
| 장면 전환 | 장면 사이 검은 화면 페이드, 장소 이름 띠 |
| 캐릭터 연출 | 등장·퇴장 슬라이드, 말하는 사람 살짝 앞으로, 표정 바뀔 때 깜빡임 없이 교체 |
| 반박 연출 | 화면 정지 → "반박!" 컷인 → 흔들림 → 증인 표정 변화 |
| 컷 획득 | 컷이 화면 가운데로 날아와 수첩에 들어가는 연출 |
| 페이지 재생 | 퍼즐 완성 후 칸이 하나씩 밝아지며 말풍선 타자 + 의성어 효과음 (기획서 07 §5) |
| 이미지 미리 불러오기 | 장면 시작 전에 그 장면 이미지를 미리 받아 깜빡임 제거 |

### 4단계 — 소리

| 할 일 | 담당 | 내용 |
|---|---|---|
| 출처 정하기 | 사용자 | ① 무료 CC0 음원(Kenney, OpenGameArt 등) ② AI 작곡 도구로 직접 생성 중 선택 |
| BGM 5곡 | 사용자/Claude | 사무실(느긋), 탐색(밤 항구), 심문(긴장), 진실(감정), 에필로그(따뜻) |
| 효과음 약 20개 | Claude | 대사 넘김, 컷 획득, 반박, 오답, 정답, 페이지 넘김, 의성어(쿵, 띵동, 쏴아…) |
| 오디오 엔진 | Claude | 장면별 BGM 크로스페이드, 효과음 큐, 음량 설정, 첫 클릭 전 자동재생 차단 대응 |

### 5단계 — 이벤트 CG (GPT)

중요한 순간을 상반신+배경 대신 한 장짜리 그림으로. 풀컬러 도트 1536×1024, 4~6장.

- 결론: 미츠루가 히마리를 끌어당기는 진실의 순간
- 결론: 완성된 원고 페이지를 넘기는 레이
- 타이가가 편의점으로 뛰어가는 뒷모습
- 에필로그: 카페 「여백」의 레이와 코하루
- 시오리가 창밖에 서 있는 장면

### 6단계 — 편의 기능 (Claude)

| 할 일 | 내용 |
|---|---|
| 자동 저장 · 이어하기 | 장면이 바뀔 때 `localStorage`에 저장, 타이틀에 "이어하기" |
| 대사 로그 | 지난 대사 다시 보기 (휠 위 / 버튼) |
| 빨리감기 · 자동 진행 | 읽은 대사 넘기기 |
| 설정 | 글자 속도, BGM·효과음 음량 |
| 모바일 점검 | 세로 화면 안내, 터치 영역 크기 |

### 7단계 — 화면별 다듬기 (Claude, 2단계 UI 스킨 뒤)

- **심문**: 증인 컷을 크게 가운데로, 증언 문장과 [반박!] 버튼 배치 정리, 증인의 마음 게이지를 아이콘으로
- **퍼즐**: 원고지 바탕, 드래그로 칸 옮기기, 놓을 칸 강조, 완성 시 페이지 재생
- **결론**: 질문 하나에 후보 카드 4~5장만 크게, 고르면 넘어가는 방식
- **수첩**: 컷·대사 탭 구분, 컷 크게 보기

### 8단계 — 시나리오와 검증

- 대사 톤 정리(코하루 말투, 레이 독백), 튜토리얼 설명 줄이기
- Playwright로 전 장면 자동 플레이 → 오류·빈 이미지 검사를 CI에 추가
- 처음부터 끝까지 직접 플레이 테스트 → 막히는 곳·지루한 곳 기록

## 추천 순서

1. **지금**: 1단계 GPT 요청(진행 중) + Claude는 그림 없이 되는 **3단계 연출**과 **6단계 저장·로그**부터.

4. **4단계 소리**: 출처가 정해지면 바로.
5. **5단계 CG**, **8단계** 마무리.
