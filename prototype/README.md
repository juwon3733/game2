# 컷 배열 퍼즐 프로토타입 (M1)

1장 「낙하」의 컷 배열 퍼즐 두 페이지를 회색 박스로 구현한 웹 프로토타입. 그림 대신 글로 컷 내용을 적었다.

## 실행

`index.html`을 브라우저로 바로 열어도 된다. 로컬 서버가 필요하면 (python/node 없이):

```powershell
powershell -ExecutionPolicy Bypass -File prototype/serve.ps1
```

그 다음 http://localhost:8123 접속.

## 들어 있는 것

| 페이지 | 칸 | 컷 | 확인하려는 것 |
|---|---|---|---|
| 1. 그날 밤, 5층 | 4 | A B C D | 기본 배열, 경계선 모순 피드백 |
| 2. 히마리의 베란다 | 6 | A C D F G H I (A는 함정) | 함정 컷, 말풍선 붙이기(모양 규칙), 클립 고정 |

- 드래그 앤 드롭 (마우스/터치) + 클릭으로 집고 놓기
- 오답 시: 태그 전이 규칙으로 모순 경계 표시, 함정 컷 표시, 말풍선 오답 표시
- 맞은 칸 클립 고정 (앞에서부터 연속으로 맞은 칸, 옵션)
- 토와 힌트 3단계, 시오리 힌트 (페이지당 1회)
- 정답 시 페이지 재생 연출 + 레이 대사, 마지막에 원고 평가

## 심문 프로토타입 (M2) — `interrogation.html`

1장의 심문 3개(오오쿠보 → 타이가 → 히마리)를 이어서 플레이한다.

| 증인 | 왜곡 | 풀이 |
|---|---|---|
| 오오쿠보 | 미화, 낙서 | 파고들기로 「구급차!」 획득 → 컷 D(쿵)를 증언 1과 2 사이에 끼움 |
| 타이가 | 과장, 생략 | 동의 선택지 → 컷 E에 「구급차!」를 붙이고 증언 3 뒤에 끼움 |
| 히마리 | 크레용 | 파고들기로 「히마리, 움직이지 마!」 획득 → 컷 C에 붙여 아무 틈에나 보여줌 |

- 증언 컷을 눌러 넘기기, 파고들기(페널티 없음, 대사 조각/숨은 디테일 획득)
- 내 컷을 증언 사이 틈(▼)에 끌어 넣기. 틀리면 잉크 −1, 0이면 그 증인 처음부터
- 맞는 컷을 틀린 자리에 넣거나 말풍선이 틀리면 코하루가 한 줄 힌트
- 코하루 개입: 잉크 1일 때, 1장 전체 2회. 잉크 +1, 봐야 할 증언 컷에 밑줄
- 반박 성공 시 "탁!" 연출, 왜곡이 벗겨지고 새 컷 획득
- 끝나면 증인별 잉크 손실/재시작/코하루/파고들기 통계

## 파일

| 파일 | 내용 |
|---|---|
| `data.js` | 컷, 상태 태그 순서, 대사 조각, 페이지 정의 |
| `main.js` | 상태 관리, 판정, 힌트, 입력, 렌더 |
| `style.css` | 원고지 스타일 |
| `interrogation.html` / `.js` / `.css` | 심문 프로토타입 |
| `interrogation-data.js` | 증인 3명의 증언, 파고들기, 정답, 대사 |
| `serve.ps1` | 정적 서버 |
