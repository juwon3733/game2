# 같은 하루, 다른 칸 (가제)

> 기억을 만화 컷으로 꺼내 보는 조사관이, 뒤섞인 컷을 다시 배열해 사건의 진실을 맞춘다.
> 그런데 어떤 컷은 거짓말을 한다.

애니풍 도트 그래픽의 **스토리 + 퍼즐 + 추리/심문** 어드벤처.
