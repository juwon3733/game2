이미지 넣는 순서
  1. 카드의 [프롬프트 복사]를 눌러 ChatGPT에 붙여넣는다. 캐릭터는 그룹의 [설정화 먼저]를 같은 대화창에서 먼저 뽑는다.
  2. 받은 이미지를 카드에 적힌 파일명 그대로 저장한다. ([파일명 복사] 사용)
  3. 그룹 제목 옆의 [GitHub에 올리기]를 누르면 그 폴더의 업로드 화면이 열린다. 파일을 끌어다 놓고, 아래 Commit changes에서 Create a new branch를 고르고 assets/로 시작하는 이름을 붙여 Propose changes → Create pull request.
  4. PR에서 자동 검사가 파일명과 크기를 확인한다. 통과하면 Merge. 몇 분 뒤 게임에 반영된다.
빨간 카드가 아직 없는 이미지다. 없는 이미지는 게임에서 임시 그림으로 대신한다.
